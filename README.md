# My-Skill
## java-source-analyzer

### 描述

用于阅读 Java 开源项目源码（JDK、Spring Boot、MyBatis、Netty、RocketMQ、Redis、MySQL Connector、JVM、Dubbo、Kafka、Eureka、Nacos、Consul、ZooKeeper 等），分析实现原理、理解工作流程或创建带可视化图表的技术文档。

## gen-solution-viz

### 描述

基于设计规范生成 LeetCode 题解的交互式可视化 HTML。生成的 HTML 采用深色主题，包含代码高亮、变量实时更新、数据结构可视化（数组、链表、树等）、步骤控制等功能，帮助用户直观理解算法执行过程。
